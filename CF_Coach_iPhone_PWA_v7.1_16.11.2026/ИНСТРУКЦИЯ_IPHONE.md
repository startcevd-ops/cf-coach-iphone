# CF Coach — версия для iPhone (PWA), 16.11.2026

В этой папке готовая версия CF Coach для установки на экран «Домой» iPhone через Safari.
Сохраняет дизайн v6.3 из Android-проекта, тренировочные программы, упражнения,
локальный AI Coach, питание, прогресс, конструктор и таймеры.

## Как установить на iPhone через Netlify (без Mac и App Store)

1. Распакуйте ZIP на компьютере. Внутри находятся index.html и остальные файлы приложения.
2. Откройте https://app.netlify.com/drop и загрузите **папку** CF_Coach_iPhone_PWA_v7.1_16.11.2026
   с index.html в корне. Если сайт попросит войти, выполните вход.
3. Получите HTTPS-адрес вида https://имя-сайта.netlify.app.
4. Откройте этот адрес **в Safari на iPhone**.
5. Нажмите «Поделиться» → «На экран «Домой»» (или «Добавить на экран Домой»).
6. Запускайте CF Coach с иконки. После первого успешного открытия веб-ресурсы кэшируются
   для последующего использования без интернета.

Также можно разместить файлы на собственном HTTPS-хостинге или GitHub Pages.
Важно: не открывайте index.html напрямую из приложения «Файлы» — установка PWA
и работа Service Worker требуют HTTPS.

## Ограничения iPhone/PWA

- Поддержка браузерного звука и русской речи зависит от iOS и настроек устройства.
- При блокировке экрана или уходе приложения в фон iOS может остановить звук/таймер.
  После возвращения экран таймера корректирует оставшееся время по часам устройства.
- Функции, привязанные к Android TimerService, не переносятся в iPhone как нативные сервисы.
- Локальные данные с ранее установленного Android-приложения **не копируются** автоматически.
  На iPhone создаётся отдельное хранилище браузера; не удаляйте сайт/данные Safari без резервной копии.
- Если серверный AI endpoint указан, он работает только при доступности HTTPS-сервера,
  а его CORS-настройки должны разрешать ваш адрес сайта. Локальный аналитический AI работает без него.
- Загрузка архива в публичный хостинг делает файлы программы публично доступными;
  личные записи остаются на устройстве в localStorage, если вы не настроите облачный AI endpoint.

## Структура

- index.html — приложение;
- cfcoach-v63.css / cfcoach-v63.js — интерфейс;
- ios-compat.js — браузерные голос/сигналы, согласование таймера при возврате в приложение;
- manifest.webmanifest — иконка и параметры установки;
- sw.js — офлайн-кэш;
- media/, tech/ — иллюстрации и техника.

Это PWA, не нативное .ipa. Для нативной установки через TestFlight нужен отдельный iOS-проект и сборка для Apple.
