# CF Coach v7.5 / 16.11.2026 — Ми Band 10, Apple Health

## Новое

- В «Профиле» появился раздел **Mi Band 10**.
- Импорт через Apple Health: поддерживается `export.xml` и небольшой экспортный ZIP (до 30 МБ).
- Сводка за последний день и история за 7 дней (из доступных записей последних 30 дней): шаги, пульс, пульс покоя, сон, активные калории, количество тренировок.
- Предпочтение источнику Mi Fitness/Xiaomi, чтобы не суммировать шаги браслета и iPhone.
- Источник и время последнего импорта, предупреждение при отсутствии показателей Xiaomi.
- Локальное хранение и кнопка удаления импортированных показателей.
- Отдельный блок Mi Band 10 на главном экране.
- Новая версия офлайн-кэша для GitHub Pages.

## Тестирование (тестовые записи, не настоящий браслет)

- XML экспорт: успешный импорт шагов, ЧСС, сна, калорий, тренировки.
- ZIP экспорт: успешный импорт содержимого `export.xml`.
- Повторный импорт: перезапись сводки без добавления дублей.
- Изолирование iPhone-шагов от Mi Fitness-шагов: проверено.
- Профиль, главная, упражнения, тренировки, программы, питание, AI, таймер: открываются в эмуляции мобильного браузера.
- Обнуление импортированных показателей: проверено.
- JS runtime errors в тестах: не обнаружены.

## Ограничения

Это **не прямая автоматическая синхронизация** с Mi Band 10. PWA не может считывать HealthKit без нативного приложения iOS. Браслет не тестировался физически — реальное наличие метрик зависит от Mi Fitness → Apple Health и настроек разрешений. Импорт последнего файла не обновляется в фоне.

## Установка на существующий GitHub Pages

Распакуй архив обновления и загрузи **его содержимое**, сохранив расположение файлов, в корень репозитория `startcevd-ops/cf-coach-iphone` (Add file → Upload files). Убедись, что новый `mi-band-sync.js` лежит рядом с `index.html`. После Commit changes и обновления GitHub Pages открой сайт, затем в Профиле выбери Mi Band 10.
