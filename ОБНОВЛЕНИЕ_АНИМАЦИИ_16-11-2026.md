# CF Coach v7.2 — демонстрации движений атлетов

Обновлён каталог «Упражнения» для iPhone (PWA). Вместо схематичных человечков добавлены реалистичные иллюстрации фаз для 9 упражнений: Clean, Snatch, Jerk, Front Squat, Deadlift, Toes to Bar, Dips, Muscle-up, Box Jump.

В подробной карточке 8 упражнений доступна анимация — нажмите «Показать все фазы», чтобы переключиться на три фотографии, и «Смотреть движение», чтобы вернуть анимацию. Для Muscle-up есть пока только статичная иллюстрация. Для Pull-up, Back Squat и Kettlebell Swing пока сохранены старые схемы: подходящей надёжной реалистичной последовательности нет.

**Внимание:** изображения сгенерированы ИИ; это лишь наглядные иллюстрации, а не удостоверенные обучающие материалы. При выполнении рывка, взятия на грудь, толчка и гимнастических движений сверяйте технику с тренером.

## Обновление существующего GitHub Pages

1. Откройте репозиторий `startcevd-ops/cf-coach-iphone`.
2. Выберите **Add file → Upload files**.
3. Загрузите содержимое этого ZIP, **не папку целиком**. Файлы должны лежать в корне репозитория.
4. Подтвердите **Commit changes**. Старые файлы с совпадающими именами обновятся.
5. После завершения GitHub Pages откройте `https://startcevd-ops.github.io/cf-coach-iphone/`.
6. Если на iPhone видно прежние картинки, полностью закройте приложение и откройте заново через Safari; при необходимости удалите ярлык приложения и установите его заново с Safari.

Уже сохранённые результаты тренировок не удаляются.
